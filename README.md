# alu-shell

A collection of shell scripting projects covering shell basics, file
permissions, I/O redirection and filters, and shell initialization files,
variables, and expansions. Each numbered project lives in its own
directory with its own README.md describing the individual scripts.

## Projects

- basics - fundamental shell commands and scripting.
- permissions - Linux file permissions: chmod, chown, chgrp, su.
- io_redirections_and_filters - I/O redirection, pipes, and text filters (head, tail, find, sort, uniq, grep, tr, rev, cut).
- init_files_variables_and_expansions - shell init files, local/global variables, arithmetic and base-conversion expansions.
