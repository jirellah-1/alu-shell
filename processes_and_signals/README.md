# Linux Processes and Signals

This project covers Linux processes, process IDs, signals, and process management.

## Tasks
- 0-what-is-my-pid: Display the script PID.
- 1-list_your_processes: List running processes.
- 2-show_your_bash_pid: Display Bash-related processes.
- 3-show_your_bash_pid_made_easy: Find Bash processes without ps.
- 4-to_infinity_and_beyond: Print a message indefinitely.
- 5-dont_stop_me_now: Stop the infinity process using kill.
- 6-stop_me_if_you_can: Stop the infinity process without kill.
- 7-highlander: Handle SIGTERM.
- 67-stop_me_if_you_can: Send SIGTERM to Highlander.
- 8-beheaded_process: Forcefully terminate Highlander.
- 10-process_and_pid_file: Manage signals and a PID file.
- manage_my_process: Write a heartbeat message.
- 11-manage_my_process: Start, stop, and restart a process.

## Concepts
A PID is a process identifier.
A process is a running instance of a program.
Signals notify processes or request actions.
SIGKILL and SIGSTOP cannot be caught, blocked, or ignored.
